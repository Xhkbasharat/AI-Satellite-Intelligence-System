
# Changelog

All notable changes to the AI Satellite Intelligence System will be documented here.

This project follows a simple versioning convention.

## [1.0.0] - 2026-11-27

### Added
- Initial project structure.
- Satellite image preprocessing utilities.
- U-Net semantic segmentation architecture.
- Pixel-level change detection baseline.
- Geospatial processing utilities.
- Segmentation visualization tools.
- PyTorch dataset and training pipeline.
- Model evaluation utilities.
- Flask web dashboard.
- Satellite image upload interface.
- Automated test files.
- Project documentation.
- MIT License.

### Development Notes
- A trained model checkpoint is not included.
- Dataset preparation is still required.
- Model performance has not yet been established through real-world evaluation.
- Change detection requires correctly aligned imagery.

## Planned Improvements
