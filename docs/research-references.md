
# Research References

This document lists foundational research and technical resources relevant to the AI Satellite Intelligence System.

## 1. U-Net Architecture

**Paper:** U-Net: Convolutional Networks for Biomedical Image Segmentation

**Authors:** Olaf Ronneberger, Philipp Fischer, Thomas Brox

**Year:** 2015

**Link:** https://arxiv.org/abs/1505.04597

**Relevance:** Introduces the encoder-decoder architecture with skip connections used as the foundation for this project's segmentation model.

## 2. Deep Learning for Remote Sensing

**Paper:** Deep Learning in Remote Sensing: A Comprehensive Review and List of Resources

**Authors:** various researchers

**Link:** https://arxiv.org/abs/1710.03959

**Relevance:** Provides background on deep learning applications in remote sensing.

## 3. PyTorch Documentation

**Resource:** Official PyTorch Documentation

**Link:** https://pytorch.org/docs/stable/index.html

**Relevance:** Reference for model development, tensor operations, training, and evaluation.

## 4. Rasterio Documentation

**Resource:** Official Rasterio Documentation

**Link:** https://rasterio.readthedocs.io/

**Relevance:** Reference for reading and processing geospatial raster imagery.

## 5. GeoPandas Documentation

**Resource:** Official GeoPandas Documentation

**Link:** https://geopandas.org/en/stable/

**Relevance:** Reference for geographic data processing and spatial analysis.

## 6. OpenCV Documentation

**Resource:** Official OpenCV Documentation

**Link:** https://docs.opencv.org/

**Relevance:** Reference for image loading and computer vision operations.
